# VibeBeat

A simple, fast MP3 player with playlists, album art, spectrum bars and
Light, Dark and Green-on-Black themes. Built with Python + PySide6.

## Run from source
    python3 -m venv .venv && source .venv/bin/activate
    pip install -r requirements.txt
    python main.py

## Install (Kubuntu/Ubuntu)
Download the `.deb` from Releases, then: `sudo apt install ./vibebeat_*_amd64.deb`

## Windows
Download `vibebeat-windows.zip` from Releases, unzip, run `vibebeat.exe`.
